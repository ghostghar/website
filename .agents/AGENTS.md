# Goshtghar Design System & Layout Rules

All future work on this codebase MUST adhere strictly to the existing design system, visual identity, and layout structure:

- **Color Tokens** (`tailwind.config.ts`):
  - Brand Red: `#ED1C24` (Hover: `#C8151C`)
  - Brand Black / Dark: `#171717` / `#1C1C1C`
  - Soft Pink / Cream Backgrounds: `#F7E3DF` / `#F6F2EE`
  - Muted Grey: `#767676`
  - Border Color: `#ECECEC`
- **Typography**:
  - `Poppins` font family with weights 300 to 800.
- **Layout Structure**:
  - Container width restricted to `1200px` (`max-w-container mx-auto px-5`).
- **Visual Style**:
  - Consistent navigation header, hero section style, red accent badges, rounded action buttons (`rounded-full` or `rounded-md`), and clean card grid patterns.
